# Dari Monolith PHP ke Modern Frontend

Sebagian besar pengalaman saya berada di dunia *backend* dengan PHP dan MySQL. Namun, untuk portofolio ini, saya ingin sesuatu yang terasa sangat cepat, modern, dan interaktif. Pilihan saya jatuh pada **Next.js**.

## Pergeseran Paradigma

Berpindah dari arsitektur *Monolith* (seperti Laravel Blade) ke arsitektur berbasis komponen (React) membutuhkan sedikit penyesuaian logika.

```tsx
// Di React/Next.js, UI dibangun dari komponen-komponen kecil
export function Button({ variant, children }) {
  return (
    <button className={`btn-${variant} px-4 py-2 rounded-md`}>
      {children}
    </button>
  );
}
```

## 3 Alasan Menyukai Next.js

1. **Kecepatan:** Kemampuan *Static Site Generation* (SSG) membuat halaman web saya memuat niem-instan.
2. **Tailwind CSS:** Meskipun awalnya kelas-kelas di HTML terlihat berantakan, Tailwind sangat mempercepat proses *styling* tanpa harus bolak-balik file CSS.
3. **Vercel Deployment:** Pengalaman *deploy* dari GitHub ke *live server* hanya dengan hitungan detik tanpa perlu mengonfigurasi *cPanel* atau VPS.

## Wrap-up

Sebagai seorang pengembang perangkat lunak, memiliki dasar *backend* yang kuat (seperti memahami logika *database* dan API) membuat pembelajaran *frontend modern* menjadi jauh lebih bermakna dan terarah.
